# Security Policy

## Supported Versions

Only the latest version of this project is actively maintained with security updates.

| Version        | Supported |
| -------------- | --------- |
| latest         | ✅         |
| older versions | ❌         |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.

Instead, report it privately by contacting the maintainer through GitHub.

You can report vulnerabilities by:

* Opening a private security advisory (if enabled on GitHub), or
* Contacting the maintainer directly via GitHub profile

You should expect:

* An initial response within a reasonable timeframe (usually a few days)
* Updates during investigation and fix process
* A fix release before any public disclosure when applicable

We take security issues seriously and will address valid reports as quickly as possible.
